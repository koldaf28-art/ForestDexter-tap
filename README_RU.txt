FORESTDEXTER TAP — ANDROID 1.0 (офлайн-оболочка игры v0.9)

Сборка APK бесплатно:
1. Установите Android Studio на компьютер с Windows, macOS или Linux.
2. Распакуйте архив и выберите Open -> папка ForestDexterTap-Android.
3. Дождитесь Gradle Sync (первый раз нужен интернет для Android SDK и Gradle).
4. Меню Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. Найдите файл app/build/outputs/apk/debug/app-debug.apk.
6. Перенесите APK на Android и установите. Возможно, потребуется разрешить установку из этого источника.

Важные ограничения:
- Это Android-приложение с встроенной HTML-игрой, без браузерной адресной строки.
- Данные сохраняются только на этом телефоне, очистка данных приложения удалит прогресс.
- Игровые монеты и души демонстрационные. Для реального обмена нужен серверный API и проверка начислений.
- Это исходный проект, не готовый собранный APK: для сборки нужен Android Studio.
- Для публичного распространения стоит настроить постоянный ключ подписи release APK.
